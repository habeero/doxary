# Doxary UI/UX

This domain is authoritative for Doxary presentation, interaction, navigation, screen behavior, visual design, RTL, accessibility, and UI/UX validation.

Ordinary UI/UX work should be understandable from this domain alone. Consult another documentation domain only when a task genuinely depends on an implementation contract outside presentation or interaction behavior.

## Documents

- [Design system](DESIGN_SYSTEM.md) — visual language, tokens, hierarchy, RTL, accessibility, and reusable patterns.
- [Navigation](NAVIGATION.md) — primary destinations, focused flows, and entry/exit behavior.
- [Screens](SCREENS.md) — screen purposes, content hierarchy, and user-visible states.
- [Interactions](INTERACTIONS.md) — user actions, selection, dialogs, review, retry, and create/edit behavior.
- [Testing](TESTING.md) — observable UI/UX acceptance and validation.
- [Changelog](CHANGELOG.md) — concise history of established UI/UX decisions.

Approved design assets are stored in [design/wireframes](design/wireframes/) and [design/visual-reference](design/visual-reference/).
